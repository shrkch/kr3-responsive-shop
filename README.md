# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного
HTML/CSS-сайта интернет-магазина или каталога товаров.

Основа проекта — HTML/CSS-сайт из контрольной работы №1 (`kr1-html-css-shop`).

## Lighthouse

Проверены страницы:

- `index.html`;
- `catalog.html`;
- `order.html`.

Результат Accessibility: 100 на всех трёх страницах.

Отчёт сохранён в папке `lighthouse/`: скриншот `accessibility-report.png` и полные HTML-отчёты по каждой странице.

## Исправления доступности

- добавлена ссылка «Перейти к основному содержимому» (`.skip-link`), у `main` добавлен `id="main"`;
- добавлен общий стиль видимого фокуса `:focus-visible` (обводка 3px);
- текущая страница в меню отмечена `aria-current="page"` (в том числе на новой странице `order.html`);
- в таблице характеристик заголовки столбцов и строк размечены через `th` с атрибутом `scope`;
- у всех полей формы есть `label`, связанный через `for` и `id`;
- у изображений товаров есть осмысленный `alt` с названием модели;
- у модального окна есть заголовок (`aria-labelledby`) и кнопка «Закрыть» с текстом;
- Lighthouse серьёзных проблем не нашёл, контраст основных цветов достаточный.
